# Scopebook

Сервис для фрилансеров и небольших студий: рассчитывайте стоимость проекта, проверяйте маржу, фиксируйте объём работ и формируйте предложение для клиента. Дополнительные задачи можно оценить отдельной сметой.

Русский и английский языки доступны для всего интерфейса, шаблонов, уведомлений, документов и примеров PDF. Язык определяется по настройкам браузера. Переключатель **RU / EN** в верхней части сайта запоминает ваш выбор. Смена языка не перезаписывает существующие предложения и введённый вами текст. Форматы чисел и дат меняются; валюта и суммы автоматически не конвертируются.

## Запуск на компьютере

Нужны **Node.js 24**, npm и Git. Бесплатная версия работает без ключей API и внешних сервисов.

```bash
git clone https://github.com/Dank0m/GPTrepo.git
cd GPTrepo
npm ci
npm run dev
```

Откройте в браузере адрес `http://localhost:5173`. Редактор находится по пути `/app`, готовый пример — `/app?sample=1`. Терминал должен оставаться запущенным. Vite работает на порту 5173 и перенаправляет запросы API на Express, порт 3001.

Если папка уже существует, используйте её: повторное клонирование не требуется. При выборе другого адреса задайте `APP_URL`, совпадающий с адресом в браузере.

## Возможности

- Смета по задачам, часам и ставкам; валюты USD, EUR и GBP.
- Запас времени, внутренняя стоимость часа, фактическая ставка и расчётная маржа.
- Включённые работы, исключения, количество правок, сроки, предоплата и налог с продаж.
- Предпросмотр документа для клиента, печать / сохранение PDF и скачивание HTML.
- Отдельные предложения на дополнительные работы.
- Локальное сохранение, поиск, копирование, удаление и импорт резервных копий.

Внутренние ставки и расчёт маржи не включаются в документ для клиента. Маржа — плановая оценка сверх бюджета вашего времени, без накладных расходов, комиссий и налогов на доход. Экспортируемое предложение не является подписанным договором или счётом. Электронная подпись, приём оплаты от клиентов и синхронизация проектов с облаком не встроены.

## Тарифы и данные

Бесплатно можно сохранить одно предложение. Планируемая цена **Pro — 29 долларов одним платежом**: до 500 предложений, документы без отметки Scopebook и резервные копии. Продажи и спрос пока не подтверждены; [исследование рынка](docs/MARKET_RESEARCH.md) и [план запуска](docs/LAUNCH.md) описывают гипотезу.

Предложения и настройки хранятся в этом браузере. После очистки данных сайта или перехода в другой браузер они не восстановятся автоматически. Сохраняйте документы и приватные резервные копии. Формат JSON совместим между русской и английской версиями; ограничения резервной копии — 500 предложений и 5 МБ.

Лицензия Pro хранится отдельно: в защищённом cookie и базе SQLite на сервере. Ключ из настроек восстанавливает Pro в другом браузере, но не переносит сами проекты. Храните ключ в секрете. Платные функции доступны после подтверждённой оплаты; без настроенных ключей Stripe покупка отключена.

## Публикация и платежи

Сборка для публикации:

```bash
npm ci
npm run build
APP_URL=https://ваш-домен NODE_ENV=production npm start
```

Последняя команда приведена для Bash. Подставьте настоящий HTTPS-домен либо задайте переменные через настройки хостинга. Сервер работает на порту 3001 по умолчанию; `PORT` меняет порт.

Для приёма оплаты владелец должен подключить свой Stripe. Перечень переменных находится в `.env.example`: `STRIPE_SECRET_KEY`, `STRIPE_WEBHOOK_SECRET`, необязательный `STRIPE_PRICE_ID`. Не публикуйте секреты в Git и не отправляйте их в чат. Настройте webhook `/api/billing/webhook` и пройдите настоящую тестовую оплату, возврат и восстановление лицензии до включения реальных платежей. Подробная техническая инструкция и список событий — в [английском README](README.md#connect-payments-when-ready-to-sell).

Серверу нужен доступ к `api.stripe.com`, а базе лицензий — постоянный диск и резервное копирование. По умолчанию база находится в `.data/scopebook.sqlite`; `DATABASE_PATH` задаёт другой путь. Временная файловая система без постоянного диска не подходит для реальных продаж. В репозитории также есть Dockerfile. Сам контейнер в среде разработки не собирался.

## Проверки

```bash
npm run build
npm test
npm run test:e2e
```

Браузерные тесты проверяют английскую и русскую версии на компьютере и мобильном экране: смену и сохранение языка, сохранность текста, документы, копии, сообщения об ошибках и существующие сценарии приложения. Если системного Chromium нет, установите его командой `npx playwright install chromium`; `CHROMIUM_PATH` позволяет указать другой исполняемый файл. Перед браузерными тестами нужна сборка.

Команда `npm run samples` заново создаёт демонстрационные PDF и HTML на двух языках. Для неё также нужен Chromium.
